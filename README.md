# Real Home.

A lightweight, high-performance **New Tab** Chromiun browser extension built with Manifest V3. Designed for minimalism, speed, and privacy.

## Features

- **Glassmorphism UI:** Minimalist dark mode design with modern blurred aesthetics.
- **Custom Wallpaper Storage:** Uses `IndexedDB` to store high-resolution wallpapers locally on your device without slowing down browser performance.
- **Drag-and-Drop Backgrounds:** Simply drag any local image into your settings panel to update your wallpaper instantly.
- **Customizable Search Engines:** Switch seamlessly between Google, DuckDuckGo, Bing, and Brave Search.
- **Dynamic Bookmark Grid:** Add, edit, and delete quick-access site shortcuts directly from your main dashboard with automatic favicon fetching.
- **Privacy-First:** Zero tracking, zero telemetry, and fully self-contained in local storage.
- **No Annoying Pop Up:**
No Ads, And more.
## NEW Features 

- **Mic and Image Input:** Added voice search (microphone) and quick image search integration. (kinda broke)

## Tech Stack

- **Manifest Version:** V3
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Storage:** IndexedDB (for wallpapers), `localStorage` (for settings & shortcuts)
