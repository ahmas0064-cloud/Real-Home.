Installation Guide

1

Clone or Download Repository

Run git clone https://github.com/ahmas0064-cloud/Real-Home..git or download the ZIP from GitHub.

2

Open Browser Extensions Page

Go to chrome://extensions or brave://extensions in your browser address bar.

3

Enable Developer Mode & Load

Toggle Developer Mode in the top right, click Load unpacked, and select your extension folder.
